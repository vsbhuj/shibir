## 🙏 શિબિરમાં પધારનારા સંતો (કુલ 52)

### દેવકૃષ્ણસ્વામી મંડળ (6)

1. સ્વામી કુંજવિહારીદાસજી
2. સ્વામી ઘનશ્યામનંદનદાસજી
3. સ્વામી રામકૃષ્ણદાસજી
4. સ્વામી પતિતપાવનદાસજી
5. સ્વામી મુકુંદદાસજી
6. સ્વામી રામદાસજી

### પૂજ્ય ઉપમહંત સ્વામી (6)

1. સ્વામી સંતસ્વરૂપદાસજી
2. સ્વામી કપિલમુનિદાસજી
3. સ્વામી હૃદયપ્રકાશદાસજી
4. સ્વામી વેદપ્રકાશદાસજી
5. સ્વામી વાત્સલ્યમુનિદાસજી
6. પાર્ષદ સંજય ભગત

### મહંત સ્વામી મંડળ (13)

1. સ.ગુ. સ્વામી મુક્તવલ્લભદાસજી
2. સ્વામી ઘનશ્યામસ્વરૂપદાસજી
3. સ્વામી હરિમુકુંદદાસજી
4. સ્વામી ઘનશ્યામપ્રસાદદાસજી
5. સ્વામી શ્યામકૃષ્ણદાસજી
6. સ્વામી ધર્મકિશોરદાસજી
7. સ્વામી ન્યાલકરણદાસજી
8. સ્વામી હરિપ્રિયદાસજી
9. સ્વામી હરિવત્સલદાસજી
10. સ્વામી બાલમુકુંદદાસજી
11. સ્વામી ભક્તિવલ્લભદાસજી
12. સ્વામી ભગવાનદાસજી
13. સ્વામી માધવજીવનદાસજી

### દેવપ્રકાશદાસજી સ્વામી મંડળ (5)

1. સ્વામી કૃષ્ણપ્રકાશદાસજી
2. સ્વામી જ્ઞાનપ્રકાશદાસજી
3. સ્વામી મોરલીમનોહરદાસજી
4. સ્વામી હરિપ્રસાદદાસજી
5. સ્વામી આનંદપ્રકાશદાસજી

### બાલકૃષ્ણદાસજી સ્વામી મંડળ (8)

1. સ્વામી રાઘવમુનિદાસજી
2. સદ. સ્વામી શ્રીપ્રકાશદાસજી
3. સ્વામી નૌત્તમમુનિદાસજી
4. સ્વામી વિજ્ઞાનસ્વરૂપદાસજી
5. સ્વામી રામાનુજદાસજી
6. સ્વામી ચૈતન્યમુનિદાસજી
7. સ્વામી વિવેકમુનિદાસજી
8. પાર્ષદ યોગેશ ભગત

### ગોલોકવિહારીદાસજી સ્વામી મંડળ (9)

1. શા. સ્વામી ગોલોકવિહારીદાસજી
2. સ્વામી હરિસ્વરૂપદાસજી
3. સ્વામી આનંદસ્વરૂપદાસજી
4. સ્વામી ધ્યાનસ્વરૂપદાસજી
5. સ્વામી સંતદાસજી
6. સ્વામી યોગેશ્વરદાસજી
7. સ્વામી વિશ્વસ્વરૂપદાસજી
8. સ્વામી ધ્યાનપ્રિયદાસજી
9. સ્વામી પુરૂષોત્તમદાસજી

### લક્ષ્મીપ્રસાદદાસજી સ્વામી મંડળ (3)

1. સ્વામી વિષ્ણુચરણદાસજી
2. સ્વામી નિર્ભયસ્વરૂપદાસજી
3. સ્વામી નિર્ભયજીવનદાસજી

### કેશવજીવનદાસજી સ્વામી મંડળ (2)

1. સ્વામી વ્યાસસ્વરૂપદાસજી
2. સ્વામી નીલકંઠજીવનદાસજી
